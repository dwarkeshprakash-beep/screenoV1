## High-Impact Findings

1. Demo quick-login credentials were visible whenever configured in env. Fixed by hiding all demo account UI unless `VITE_SHOW_DEMO_ACCOUNTS=true`.
2. Monthly assessment enrollment removal used destructive semantics and tests expected hard deletion. Fixed route/service/UI/regression test to soft-cancel plans while preserving completed history.
3. Monthly assignment had a race window between conflict checks and enrollment creation. Added a transaction row lock on `team_members` before assigning candidates.
4. Candidate human interview join behavior was inconsistent: consent magic links could lose interview-scoped auth and the candidate interviews page did not expose a join action. Fixed both paths.
5. Candidate mandate resume deadlines were visible in data but not reliably shown/enforced. Added fallback deadline exposure, UI disable state, and backend 409 enforcement.
6. Candidate overview could spotlight an expired launch item ahead of a currently open interview. Fixed selection priority to prefer launchable/open items.
7. Auth layout listeners expected login/logout browser events that were not dispatched. Added login/logout event dispatching.
8. `/manager/organization/:userId` had no topbar metadata. Added route metadata.
9. Device check speaker retry text implied failure even when only speaker confirmation was pending. Tightened retry visibility and copy.
10. Clean DB setup lagged live migrations. Added migration `018` and wired it into latest/setup runners.
